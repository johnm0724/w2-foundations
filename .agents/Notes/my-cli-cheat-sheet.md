## Cloud Platforms

### AWS
- Cloud service provider by Amazon
- Used by majority of Fortune 500 companies
- Services include EC2, S3, Lambda, etc.

### GCP
- Google Cloud Platform
- Strong in machine learning and data analytics
- Popular services: Compute Engine, Cloud Storage

## Terminal Commands

### Linux
- `pwd` - print working directory
- `ls -la` - list all files including hidden
- `cd ~` - navigate to home directory

### GitHub
- `gh repo fork` - fork a repository
- `gh repo clone` - clone a repository
- `git remote -v` - view configured remotes

### Brew
- `brew install <package>` - install a package
- `brew list` - show installed packages
- `brew update` - update Homebrew itself
